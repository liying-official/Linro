# Linro v1.0.1 安全边界

[English](SECURITY.en-US.md) · [README](../README.md) · [详细手册](GUIDE.md)

## 管理与信任边界

生产入口要求 HTTPS、正确管理主机、Cloudflare Access JWT 签名与 issuer / audience / 时间校验。访问静态后台也先鉴权。交互式管理写入要求严格同源和 `X-Linro-CSRF: 1`；公开密码表单的窄来源例外不会放宽后台 CSRF。

自动化需 Access 与应用 token 双层认证。角色和 scope 每次检查；所有应用 token 只能写所属用户创建的链接。只读成员可读取共享工作区目标与纯文本，不能将该模型当成多租户隔离或保密文档库。

D1 是最新授权来源。KV 只缓存允许的路由字段，不保存密码校验串、正文、计数或根 secrets；命中仍需 D1 核验。D1 失败不能以旧缓存放行。

生产部署必须通过 `preflight` 检查全部限流绑定。当前 Admin 入口只在 `AUTH_LIMITER` 存在时调用该预认证限流器；绕过检查并手工删除它不会自动令所有管理请求返回 503。不要把这一点误读为可以省略绑定；生产认证与写入限流仍有各自独立检查。

## 公开访问边界

密码验证使用独立根 secret、HMAC pepper、随机盐及 PBKDF2-SHA256。保持两端 `LINK_PASSWORD_SECRET` 相同，升级不要重新生成。密码表单成功只回同源短码，不把 POST 密码转交目标。

浏览器时区来自不可信客户端自报；IP 时区及 Tor 信号使用平台元数据。旅行、系统设置或地理库错误都可能误判。`block_vpn` 对未知时区也拒绝；关闭全局采集不会关闭单链接策略。120 秒挑战 / 证明不是服务端消费型一次性凭据：同一有效上下文内不能宣称绝对防重放。

有限次数计数是服务端授权请求数，不是人数；获准的 HEAD 也扣一次。D1 提交后响应丢失可能保守占用名额，不保证自动退款。已经缓存到访客客户端的旧跳转不能被服务器强制收回。

Worker 限流按代码 key 和平台位置计数，不是连接级计数或全球严格配额。密码桶使用 IP 哈希、默认5次/60秒。共享出口可能共享桶；不同实例应选择独立 namespace。WAF 是额外防护，不能替代应用身份与数据校验。

目标只允许通过校验的 HTTP(S) URL；默认拒绝私有 / 本地主机和管理短链环路，但**不解析 DNS**，不是完整 DNS 重绑定防御。`source_url` 的格式校验也不能证明源码地址实际可达。

## 公开前的隐私检查

不要提交 `deployment.json`、生成后的真实 Wrangler 配置、`.env*`、`.dev.vars*`、`.local/`、数据库、SQL 备份、认证响应、日志、Cookie 或密钥。检查普通 Markdown、HTML 隐藏内容、示例、附件和截图；`.gitignore` 不会清理已经提交过的内容，发布排除规则也不是通用秘密扫描器。

文档业务示例使用 `example.com` / `example.net` / `example.org`、显式资源占位符与本地回环地址。保留上游仓库和许可证署名不等于包含测试机信息。若发现真实凭据曾公开，先撤销 / 轮换并评估访问记录，再处理受影响历史；仅删除当前文件不足以撤销秘密。

## 报告安全问题

不要在公开 issue 粘贴可用凭据、私人域名快照或业务数据。使用仓库实际启用的私密安全报告渠道；如果没有启用，先询问维护者可用的私密联系渠道，不要猜测邮箱。提供版本、影响范围、最小化且已脱敏的复现说明；仅对自己有权测试的实例进行验证。

这些说明描述源码边界，不构成“没有漏洞”、已通过渗透测试或任何合规认证的保证。
