# 安全边界

管理主机由 Cloudflare Access 保护，Worker 复核 JWT、用户状态与权限。交互式写请求检查 Origin、X-Linro-CSRF 和 Fetch Metadata；应用令牌使用最小 scope，并受所属用户权限限制。生产 workers.dev 与预览入口保持关闭。

公开短链检查域名、启停、期限、密码、次数上限及浏览器策略。KV 命中仍需最新 D1 校验；数据库故障不以旧缓存放行。浏览器时区仅是启发式信号，不能证明是否使用 VPN。

密码及浏览器检查使用独立根 secrets。保留原密码根 secret，否则既有密码可能失效。数据库备份包含敏感业务数据和哈希，须受控存储。禁止提交部署凭据、私有配置或数据库。

源码不代理目标网站，不做 DNS 解析；目标字面量校验不等于完整 DNS 重绑定防御。位置级限流不是严格全球配额。
