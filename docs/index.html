2.1 部署结构2.1 Deployment Architecture#

Linro 是带简体中文 / 英语管理界面的短链接管理平台。它部署为两个 Cloudflare Worker，共享一个 D1 数据库。管理界面是 React + Vite 构建的静态资源，由 Linro is a short-link management platform with a Simplified Chinese / English admin interface. It deploys as two Cloudflare Workers sharing one D1 database. The admin UI is static content built with React + Vite and is served by Admin Worker 的 Static Assetsthe Admin Worker’s Static Assets 提供；该版本不要求另建 Pages 项目。 ; this release does not require a separate Pages project.

If deeper logging is needed, enable it only in a controlled environment and verify redaction. Never post Authorization, Access JWT, complete cookies, password POST bodies, or private SQL to a public issue. Before database maintenance, review the exact statements and backups; there is no public API for automatic audit / archive cleanup.
